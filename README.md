# AI From Scratch 🤖

A project where I build artificial intelligence systems from the ground up to understand how they actually work.

Instead of starting with large AI frameworks, this project starts with the smallest building blocks and gradually works toward neural networks and eventually a tiny transformer.

## 🎯 Goal

Learn AI by implementing the important parts myself:

- Neurons
- Perceptrons
- Neural networks
- Activation functions
- Loss functions
- Gradient descent
- Backpropagation
- Tokenization
- Attention
- Transformers

## 🧠 V1: Artificial Neuron

The first version creates a very simple artificial neuron.

It takes inputs, multiplies them by weights, adds a bias, and produces an output.

The basic equation is:

```text
output = x₁w₁ + x₂w₂ + b
```

V1 focuses on understanding the mathematics behind a neuron before using more advanced AI libraries.

## 🚀 Long-Term Goal

The long-term goal is to go from a single mathematical neuron to a small AI system built piece by piece.

Every version will focus on understanding the underlying concepts rather than simply importing an existing AI model.

## 📌 Learning Principle

> Understand it first. Code it second. Use a library later.
